当前网页版为 **OMNI-2026-11-01-R2**；共同题与卡片沿用原 OMNI 问卷与施测者说明。保留一题一屏、选择后自动进入下一题、返回修改、自动保存和结束后详细分析的方式。

## 本版内容

- **22 个立场分面**：经济制度、公民权利、民主、组织、变革、文化、宗教、民族、国际关系、生态、技术、证据观等分别报告，不把所有立场压成一个总分。
- **9 个专题、358 张规范思想卡、196 个别名、82 项来源**：目录中的名称均有核验入口，支持检索与跨专题选择。
- **分支作答，最多 307 个响应项**：132 道共同题 → 36 道全主题筛查 → 12 道情境题与 6 项背景 → 最多两个专题各补 20 题 → 最多 57 道旧版整合补充题 → 最多四张卡各 6 项。补充题按六组自选，可全部跳过。
- **不限时、可分次继续**：没有倒计时、阶段截止或自动交卷，刷新或离开后保留进度；提交前可修改已答内容。经过时间仅作记录。
- **先主张，后名称**：默认按编号选择候选卡，先答 a/b/c，再揭示名称、询问此前熟悉度和自我认同。主动按名称选卡会记录未盲条件；揭示后修改主张保留原答与更正答。

首页介绍覆盖范围、优势及测量边界。旧版 267 题已逐题审查；57 题经七点重编纳入可选题组，取舍与来源见 [整合审计](LEGACY_INTEGRATION.md)。新增题逐题描述，保持 22 个共同分面与思想卡规则的含义。

## 结果包括什么

每个分面的方向、有效题数、缺答范围与六题原答；实际核验卡的逐项支持、反对、中立及缺答；名称认同与熟悉度；已核验近邻之间的差异；情境配对；旧版补充题的支持、反对、中立、信息缺口与原题出处；本人补充；作答完整性；所有未检验卡的范围。

**目录覆盖不等于单次全部鉴别，也不等于已验证的分类准确率。** 不对未做卡自动排除，不选出“358 个思想中的唯一赢家”，不输出意识形态概率、百分位或身份认证。历史路线、理论学派的解释仍需人工核对。

## 隐私与答卷

答案仅保存在本浏览器的新版存档中。不加载第三方脚本、字体、统计服务，不调用外部 AI，不上传答案；内容安全策略为 `connect-src 'none'`。访问 GitHub Pages 本身仍需加载网页文件。

可在作答中导出 JSON 备份，结果页可导出完整答卷、复制 OMNI1 答卷代码、下载文字报告或打印为 PDF。只在愿意分享答案时向施测者提供导出文件。公共电脑用完后请清除本机记录。

[新版计分器](https://saigyouji-yukari.github.io/ideology-survey/omni-admin.html) 支持单份与批量 JSON / 答卷代码导入、逐人报告和 CSV 汇总，不保存导入记录。旧版 267 题答卷仍由 [旧版计分器](https://saigyouji-yukari.github.io/ideology-survey/admin.html) 处理，两版不混算。

## 文件与维护

| 文件 | 用途 |
|---|---|
| `index.html`、`assets/omni-survey.js`、`assets/omni.css` | 首页、逐题与分支界面 |
| `data/registry.json`、`data/near_card_map.json`、`data/legacy_supplement.json` | 与新版文档一致的题库及实际近邻索引 |
| `scripts/build-data.py`、`assets/omni-data.js` | 将题库封装为浏览器本地脚本 |
| `assets/omni-session.js` | 流程、时限、答卷格式校验 |
| `assets/omni-engine.js` | 分面、卡片、情境、覆盖与导入导出 |
| `assets/omni-report.js` | 测试页与计分器共用的详细报告 |
| `omni-admin.html`、`assets/omni-admin.js` | 新版答卷导入与批量汇总 |
| `legacy.html`、`admin.html`、原有 `assets/*.js` | 独立保留的旧版及计分器 |

网站为静态页面，运行不依赖第三方库，也不需要构建。可在仓库目录执行 `python -m http.server 8000`，打开 `http://localhost:8000/`。GitHub Pages 从 `gh-pages` 分支根目录发布；`main` 用于维护。发布时将已核验的 `main` 提交同步到 `gh-pages`，仅更新 `main` 不会更新线上网站。

更新题库后执行 `python scripts/build-data.py`，同时更新计分规则与版本。不得用新版规则直接读取旧版本答卷。网页导入会核验版本、题型、呈现记录和分支范围。

## 验证

2026-11-01 修订检查覆盖共同题、可选补充题、思想卡、缺答处理与导出导入；同时检查超过旧截止时间及跨日续答。自动检查仅验证软件实现，结果以实际运行记录为准。

`npm test` 运行无需第三方依赖的计分与流程回归检查，包括反向计分、缺答边界、原始盲答、元数据零值、补充题范围与不限时续答。

浏览器回归：`npm install` 后执行 `npm run test:browser`。Windows 默认使用本机 Chrome，可用 `CHROME_PATH` 指定浏览器可执行文件；其他系统需预先安装 Playwright Chromium。覆盖真实点击的完整 307 响应流程、自动前进、返回修改、刷新续答、分支上限、导出与管理员导入、跨日续答、手机布局、键盘及旧版入口。截图与结果放在不提交的 `.qa/`。

这些测试验证实现是否符合公开规则，**不代表真实人群中的心理测量效度或分类准确率**。
