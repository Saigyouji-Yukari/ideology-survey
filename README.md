# 意识形态测试调查

政治立场与思想倾向评估。共 267 题，作答约 50～60 分钟，结束后自动生成详细分析。

- **开始测试：** https://saigyouji-yukari.github.io/ideology-survey/
- **施测者计分器：** https://saigyouji-yukari.github.io/ideology-survey/admin.html

## 测试结果包括什么

作答结束后，页面自动生成分析结果：

- **总结论**：一段概括你在经济、政治制度、变革路径、政党与组织、社会文化五个方面位置的文字，以及你的主张与哪个思想传统最接近。
- **与 14 个思想传统的比较**：先看核心目标是否相容，再看在区分各传统的关键问题上与其典型主张的一致程度，按接近程度排序；前三名列出简介，以及你与它一致和不同的具体主张。
- **各维度详细分析**：每个维度和分项的位置图，以及逐维度的文字解读（包括你最鲜明的态度）；另有 12 个参考维度。
- **自我认同与其他发现**：你自己选择的立场名称与分析结果的对照、最看重的议题、同一原则在不同国家的适用情况。

如果有关键问题没有回答，或两个传统分不开，页面会先请你补答几道题（不说明这些题指向哪种立场），然后再给出结论。

## 隐私

- 不收集任何身份信息，每位作答者只有一个随机的匿名编号（如 `W-7K3Q9P`）。
- 答案只保存在作答者自己的浏览器里，可以中途离开、回来继续；首页和结果页都可以“清除本机记录”。
- 页面不向任何服务器发送数据，不使用统计或第三方服务，也不加载外部字体或脚本。页面设置了内容安全策略（`connect-src 'none'`），浏览器会拦截任何联网上传。

## 需要收集答卷时

网站是静态的，没有服务器保存答卷。作答者可以在结果页底部“需要把答卷交给施测者？”里复制答卷代码（一行文字，包含全部答案），发给施测者。施测者把所有人的代码粘贴到 [计分器](https://saigyouji-yukari.github.io/ideology-survey/admin.html) 的“批量计分”里，每人一行，就能得到每个人的结论并导出结果表。纸质答卷也可以在计分器里逐题录入。

## 目录

| 文件 | 内容 |
|---|---|
| `index.html` | 测试页面（说明、逐题作答、补充题、分析结果） |
| `admin.html` | 施测者计分器（单份录入、补问卡、批量计分） |
| `assets/data.js` | 题目、作答说明、维度、思想传统的核心条件与判别题、补问卡 |
| `assets/engine.js` | 计分引擎，测试页面和计分器共用 |
| `assets/survey.js`、`assets/style.css` | 测试页面的界面 |
| `assets/admin.js`、`assets/admin.css`、`assets/examples.js` | 计分器的界面和示例答卷（虚构） |

没有构建步骤，也不依赖任何第三方库。本地预览：在仓库目录运行 `python3 -m http.server`，打开 http://localhost:8000/ 。

## 修改题目或规则

题目文字、计分方向、维度归属、核心条件和判别题都在 `assets/data.js` 里。改动时请同时修改《施测者计分说明》，两者应保持一致。计分引擎与《施测者计分说明》的规则一一对应，曾用独立编写的参考实现在 1701 份模拟答卷上逐项核对，结果一致。

## 使用边界

- 结果概括的是作答者在问卷所列议题上的表态，不是对其意识形态的诊断。
- 思想传统的比较只在问卷选定的 14 个传统之间进行，结论措辞为“接近某传统”，不写成“你是某某主义者”。页面显示的一致度是关键题上的一致比例，不是“属于某一传统的概率”。
- 门槛、核心条件和判别题是编制时确定的，尚未经过真实样本检验；不能称为“已经验证的流派分类”，也不能给出作答者在某一人群中的百分位。
- 计分方法在网页源代码中可以看到。作答者作答前看过计分方法，会影响回答，问卷第 266 题专门询问这一点。

## 参考

页面形式参考了几个开源政治倾向测试：[政治主义倾向测试](https://github.com/LuoYue-cn/political-tendencies-test)、[8values](https://github.com/8values/8values.github.io)、[SapplyValues](https://github.com/SapplyValues/SapplyValues.github.io)、[LeftValues](https://github.com/Douper2/leftvalues.github.io)、[PolitiScales](https://github.com/Conobi/politiscales)（一题一屏、可返回上一题、作答结束自动出结果、按接近程度排序、以坐标条展示维度）。本项目的题目、计分规则和代码均为独立编写，没有复制这些项目的代码。
