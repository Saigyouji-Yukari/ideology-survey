# 意识形态测试调查

[开始测试](https://saigyouji-yukari.github.io/ideology-survey/) · [施测者计分器](https://saigyouji-yukari.github.io/ideology-survey/omni-admin.html)

这是一份帮助个人梳理政治立场与思想倾向的问卷。采用一题一屏、选择后自动进入下一题的方式，支持返回修改、自动保存和结束后的详细分析。

## 本版内容

- **22 个立场分面**：经济制度、公民权利、民主、组织、变革、文化、宗教、民族、国际关系、生态、技术、证据观等分别报告，不把所有立场压成一个总分。
- **9 个专题、358 张规范思想卡、196 个别名、82 项来源**：目录中的名称均有核验入口，支持检索与跨专题选择。
- **分支作答，最多 307 个响应项**：132 道共同题 → 36 道全主题筛查 → 12 道情境题与 6 项背景 → 最多两个专题各补 20 题 → 最多 57 道补充题 → 最多四张卡各 6 项。补充题按六组自选，可全部跳过。
- **不限时、可分次继续**：没有倒计时、阶段截止或自动交卷，刷新或离开后保留进度；提交前可修改已答内容。经过时间仅作记录。
- **先主张，后名称**：默认按编号选择候选卡，先答 a/b/c，再揭示名称、询问此前熟悉度和自我认同。主动按名称选卡会记录未盲条件；揭示后修改主张保留原答与更正答。

首页介绍覆盖范围、优势及测量边界。补充题按六组自选，用于记录具体政策、治理与历史经验的看法；各题分别描述，不合成为共同分面或思想归属分数。

## 结果包括什么

每个分面的方向、有效题数、缺答范围与六题原答；实际核验卡的逐项支持、反对、中立及缺答；名称认同与熟悉度；已核验近邻之间的差异；情境配对；补充题的支持、反对、中立、信息缺口与逐题记录；本人补充；作答完整性；所有未检验卡的范围。

报告配有图表，全部在本机生成：

- **立场图谱**（报告开头）：三维罗盘，以三个分面的分值为坐标，默认所有权目标、公民自由与社会习俗，可任选、可拖动旋转；以及按六个主题排列的发散条形图，显示 22 个分面的方向与缺答范围。
- **22 个议题分面**：全景雷达图；每个主题一张雷达图和逐题得分条形图。
- **其他部分**：思想卡三项主张的作答位置与熟悉度、认同；补充题组的作答分布；甲乙情境的对照图；作答构成与选项使用次数；所选专题的逐题作答。
- **总结：作答倾向图**：仿照常见政治倾向测试的总结图，每个分面一行，两端配图标，显示偏向两端、中立与缺答的比例，并列出作答中较突出的倾向。只描述倾向，不给出“某某主义者”之类的标签。可保存为图片。

图表只把报告中已有的分值、范围和原答画出来，不另行计分；计算方式见计分规则的“图表”一节。图表的颜色写在图形本身，报告被复制到别处或用其他工具转成 PDF、丢失样式表时也能正常显示。

**目录覆盖不等于单次全部鉴别，也不等于已验证的分类准确率。** 不对未做卡自动排除，不选出“358 个思想中的唯一赢家”，不输出意识形态概率、百分位或身份认证。历史路线、理论学派的解释仍需人工核对。

## 隐私与答卷

答案仅保存在当前浏览器中。不加载第三方脚本、字体、统计服务，不调用外部 AI，不上传答案；内容安全策略为 `connect-src 'none'`。访问 GitHub Pages 本身仍需加载网页文件。

可在作答中导出 JSON 备份，结果页可导出完整答卷、复制 OMNI1 答卷代码、下载文字报告或打印为 PDF。只在愿意分享答案时向施测者提供导出文件。公共电脑用完后请清除本机记录。

[计分器](https://saigyouji-yukari.github.io/ideology-survey/omni-admin.html) 支持单份与批量 JSON / 答卷代码导入、逐人报告和 CSV 汇总，不保存导入记录。不同题号体系的答卷不直接混算。

## 文件与维护

| 文件 | 用途 |
|---|---|
| `index.html`、`assets/omni-survey.js`、`assets/omni.css` | 首页、逐题与分支界面 |
| `data/registry.json`、`data/near_card_map.json`、`data/legacy_supplement.json` | 题库与近邻索引 |
| `scripts/build-data.py`、`assets/omni-data.js` | 将题库封装为浏览器本地脚本 |
| `assets/omni-session.js` | 流程、进度与答卷格式校验 |
| `assets/omni-engine.js` | 分面、卡片、情境、覆盖与导入导出 |
| `assets/omni-report.js` | 测试页与计分器共用的详细报告 |
| `assets/omni-charts.js`、`assets/omni-charts.css` | 报告图表（三维罗盘、发散条形图、雷达图、作答倾向总览等），测试页与计分器共用 |
| `omni-admin.html`、`assets/omni-admin.js` | 答卷导入与批量汇总 |
| `legacy.html`、`admin.html`、原有 `assets/*.js` | 编制阶段的归档页面，未作为当前测评入口 |

网站为静态页面，运行不依赖第三方库，也不需要构建。可在仓库目录执行 `python -m http.server 8000`，打开 `http://localhost:8000/`。GitHub Pages 从 `gh-pages` 分支根目录发布；`main` 用于维护。发布时将已核验的 `main` 提交同步到 `gh-pages`，仅更新 `main` 不会更新线上网站。

更新题库后执行 `python scripts/build-data.py`，同时更新计分规则与版本。不得直接混算不同题号体系的答卷。网页导入会核验版本、题型、呈现记录和分支范围。

## 验证

2026-11-01 实现检查覆盖共同题、可选补充题、思想卡、缺答处理与导出导入；同时检查长时间间隔及跨日续答。自动检查仅验证软件实现，结果以实际运行记录为准。

`npm test` 运行无需第三方依赖的计分与流程回归检查，包括反向计分、缺答边界、原始盲答、元数据零值、补充题范围、不限时续答，以及图表数值与分值、缺答范围是否一致。

浏览器回归：`npm install` 后执行 `npm run test:browser`。Windows 默认使用本机 Chrome，可用 `CHROME_PATH` 指定浏览器可执行文件；其他系统需预先安装 Playwright Chromium。覆盖真实点击的完整 307 响应流程、自动前进、返回修改、刷新续答、分支上限、导出与管理员导入、跨日续答、手机布局、键盘、全部 1497 个题目在桌面宽度下单行显示、三维罗盘旋转与改选坐标轴、总览图导出及归档页面。截图与结果放在不提交的 `.qa/`。

这些测试验证实现是否符合公开规则，**不代表真实人群中的心理测量效度或分类准确率**。
