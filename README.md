# 意识形态测试调查

[开始测试](https://saigyouji-yukari.github.io/ideology-survey/) · [施测者计分器](https://saigyouji-yukari.github.io/ideology-survey/omni-admin.html)

这是一份帮助个人梳理政治立场与思想倾向的问卷。采用一题一屏、选择后自动进入下一题的方式，支持返回修改、自动保存和结束后的详细分析。

## 本版内容

- **22 个立场分面**：经济制度、公民权利、民主、组织、变革、文化、宗教、民族、国际关系、生态、技术、证据观等分别报告，不把所有立场压成一个总分。
- **9 个专题、358 张规范思想卡、196 个别名、82 项来源**：目录中的名称均有核验入口，支持检索与跨专题选择。
- **分支作答，最多 307 个响应项**：132 道共同题 → 36 道全主题筛查 → 12 道情境题与 6 项背景 → 最多两个专题各补 20 题 → 最多 57 道补充题 → 最多四张卡各 6 项。补充题按六组自选，可全部跳过。
- **不限时、可分次继续**：没有倒计时、阶段截止或自动交卷，刷新或离开后保留进度；提交前可修改已答内容。经过时间仅作记录。
- **先主张，后名称**：默认按编号选择候选卡，先答 a/b/c，再揭示名称、询问此前熟悉度和自我认同。主动按名称选卡会记录未盲条件；揭示后修改主张保留原答与更正答。

首页介绍覆盖范围、优势及测量边界。补充题按六组自选，用于记录具体政策、治理与历史经验的看法；各题分别描述，不合成为共同分面或思想归属分数。

## 结果包括什么

六个维度的基本倾向性画像、较接近流派及代表人物的肖像与介绍；每个分面的方向、有效题数、缺答范围与六题原答；实际核验卡的逐项支持、反对、中立及缺答；名称认同与熟悉度；已核验近邻之间的差异；情境配对；补充题的支持、反对、中立、信息缺口与逐题记录；本人补充；作答完整性；所有未检验卡的范围。

报告首先提供 **基本倾向性画像**：六个维度分别比较典型主张，显示思想参照、代表人物肖像与简介，并保留中立、混合、信息不足和近似并列。依据和人物来源可展开查看；不把局部接近当作完整身份。比较规则见 [PROFILE_RULES.md](PROFILE_RULES.md)，图像许可见 [PORTRAIT_SOURCES.md](PORTRAIT_SOURCES.md)。

报告配有图表，全部在本机生成：

- **立场图谱**（基本倾向性画像之后）：三维罗盘，以三个分面的分值为坐标，默认所有权目标、公民自由与社会习俗，可任选、可拖动旋转；以及按六个主题排列的发散条形图，显示 22 个分面的方向与缺答范围。
- **22 个议题分面**：全景雷达图；每个主题一张雷达图和逐题得分条形图。
- **其他部分**：思想卡三项主张的作答位置与熟悉度、认同；补充题组的作答分布；甲乙情境的对照图；作答构成与选项使用次数；所选专题的逐题作答。
- **总结：作答倾向图**：仿照常见政治倾向测试的总结图，每个分面一行，两端配图标，显示偏向两端、中立与缺答的比例，并列出作答中较突出的倾向。只描述倾向，不给出“某某主义者”之类的标签。可保存为图片。

图表只把报告中已有的分值、范围和原答画出来，不另行计分；计算方式见计分规则的“图表”一节。图表的颜色写在图形本身，报告被复制到别处或用其他工具转成 PDF、丢失样式表时也能正常显示。

**目录覆盖不等于单次全部鉴别，也不等于已验证的分类准确率。** 不对未做卡自动排除，不选出“358 个思想中的唯一赢家”，不输出意识形态概率、百分位或身份认证。历史路线、理论学派的解释仍需人工核对。

## 隐私与答卷

答案仅保存在当前浏览器中。不从第三方站点加载脚本、字体或统计服务，不调用外部 AI，不上传答案；内容安全策略为 `connect-src 'none'`。访问 GitHub Pages 本身仍需加载网页文件。

可在作答中导出 JSON 备份，也可打开“复制／分段备份”：当前代码带长度与 CRC32 校验，每段不超过 1000 字符，计分器支持乱序逐段加入、缺段提示和完整性校验；以前的 OMNI1 代码与 JSON 继续兼容。自动复制受限时可以长按选中的短段文字手动复制。结果页还可下载文字报告或打印为 PDF。

“分批导出报告图片”将整份报告的详细内容展开并分页，每批生成最多六张 PNG，在页面内预览，可逐张长按保存。图片供阅读和分享，不能代替可重新计分的答卷代码。所有渲染与校验在本机完成，截图组件随站点保存，不上传报告。QQ、微信等内置浏览器可能限制下载，首页提示优先在桌面浏览器测试；已在内置浏览器完成的答卷应在原浏览器先分段备份，复制网址不会迁移本机答案。只在愿意分享答案时向施测者提供导出文件。公共电脑用完后请清除本机记录。

[计分器](https://saigyouji-yukari.github.io/ideology-survey/omni-admin.html) 支持单份与批量 JSON / 答卷代码 / 完整分段导入、逐人报告和 CSV 汇总，不保存导入记录。不同题号体系的答卷不直接混算。

网站为静态页面，不需要构建；分页图片导出使用随站点分发的 html2canvas 1.4.1（MIT），运行时不加载 CDN。可在仓库目录执行 `python -m http.server 8000`，打开 `http://localhost:8000/`。GitHub Pages 从 `gh-pages` 分支根目录发布；`main` 用于维护。发布时将已核验的 `main` 提交同步到 `gh-pages`，仅更新 `main` 不会更新线上网站。

更新题库后执行 `python scripts/build-data.py`，同时更新计分规则与版本。不得直接混算不同题号体系的答卷。网页导入会核验版本、题型、呈现记录和分支范围。

## 验证

2026-11-01 实现检查覆盖共同题、可选补充题、思想卡、缺答处理与导出导入；同时检查长时间间隔及跨日续答。自动检查仅验证软件实现，结果以实际运行记录为准。

`npm test` 运行无需第三方依赖的计分与流程回归检查，包括反向计分、缺答边界、原始盲答、元数据零值、补充题范围、不限时续答，以及图表数值与分值、缺答范围是否一致。

浏览器回归：`npm install` 后执行 `npm run test:browser`。Windows 默认使用本机 Chrome，可用 `CHROME_PATH` 指定浏览器可执行文件；其他系统需预先安装 Playwright Chromium。覆盖真实点击的完整 307 响应流程、自动前进、返回修改、刷新续答、分支上限、导出与管理员导入、跨日续答、手机布局、键盘、全部 1497 个题目在桌面宽度下单行显示、三维罗盘旋转与改选坐标轴、总览图导出及归档页面。截图与结果放在不提交的 `.qa/`。

`npm run test:backup` 检查分段备份、复制受限的手动方式、逐段导入、坏段和缺段、旧格式兼容及恢复；`npm run test:images` 检查完整报告文字覆盖、分页图片、头像和图表、批次生成、取消与手机预览。导出协议和操作边界见 [BACKUP_EXPORT.md](BACKUP_EXPORT.md)。

这些测试验证实现是否符合公开规则，**不代表真实人群中的心理测量效度或分类准确率**。

## 项目说明

网页由 Claude-Opus-5-5 和 ChatGPT-6-Astra 协助编制与实现。网页采用本机保存和计算的方式。思想编制来源见题库与报告中各卡的来源链接。

网页版：OMNI-2026-11-01-R2

编制阶段的题目取舍与映射资料保存在 [编制审计](LEGACY_INTEGRATION.md)，供维护者追溯；不作为答题者的作答流程说明。

维护人物介绍或参照数据后执行 `python scripts/build-profiles.py`，同步 JSON 与浏览器脚本；`npm run test:profiles` 核对六维报告、头像、手机布局和导出。
