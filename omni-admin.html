支持的格式与批量处理说明

支持本测试单个答卷对象、由答卷对象组成的 JSON 数组，以及每行一个答卷代码或 JSON 对象。一次最多 200 份、总文本不超过 10 MB。每份答卷必须包含自己的格式信息、已呈现题目及分支记录；不把遗漏或未呈现的答案填成中立。

长代码可能在聊天中被截断，建议使用带长度与校验的分段备份。分段顺序不限；缺段、冲突或内容损坏会提示，不会补齐或猜测答案。以前导出的完整代码与 JSON 仍可使用。

导入会替换本页此前的答卷列表，格式有误的条目单独列出；有效条目仍可查看。仅处理本测试导出的答卷，不将其他题号体系或计分规则直接换算为本测试结果。

“导出汇总 CSV”包含编号、完成范围、22 个分面值与缺答范围、核验卡状态和自我认同。完整逐题作答请使用“导出当前 JSON”。
